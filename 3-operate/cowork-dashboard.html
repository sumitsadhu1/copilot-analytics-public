Reference views, not the billing record; assisted hours are directional

The Cowork reports are operational views, not invoices. Microsoft says: “Use the monthly billing record for reconciliation, not the usage dashboards.” Cowork assisted hours are “a directional estimate of employee hours that benefited from Cowork”, and Microsoft states that they “aren't a direct measurement of time saved, productivity gains, business outcomes, or realized value”.

1. Purpose and Current Coverage

Copilot Cowork (Cowork) reporting is split across the Microsoft 365 admin center and Viva Insights. Each surface has its own roles and definitions, so pick the surface by the question you need answered.

SurfaceUse it to answerStatus as documented
Admin center: Copilot > Cowork (Overview, Usage, Value, Settings)Adoption, retention, tasks by type, per-user tasks, and assisted hours by task categoryThe Value tab: “This feature is part of Frontier preview program.” No other tab is labelled.
Consumption Dashboard > Microsoft 365 services > Cowork (Deep dive)Credits, tasks per user, task mix, and usage intensityThe Learn article does not label the Cowork page as preview. Coverage is narrow: “Consumption data is currently available only for Copilot Cowork and the Work IQ API.”

2. Access and Scope

Cowork access comes from a spending policy, not a reporting role

Microsoft states: “Access is granted only through a spending policy that selects Cowork.” The Cowork entry under Agents > All Agents does not control it. Microsoft's billing article says the default set-up “targets your entire organization and all users”, so first-time set-up may open Cowork to everyone in that scope. That reading is the hub's inference, not Microsoft's; confirm intent before you activate a policy.

Microsoft 365 admin center: Copilot > Cowork

The Cowork page says: “To view the reporting data in this dashboard, you need the appropriate permissions.” It points to the usage-report permissions, which list Global Administrator, Exchange Administrator, SharePoint Administrator, Reports Reader, Teams Administrator, Teams Communications Administrator, and AI Administrator, plus Usage Summary Reports Reader and User Experience Success Manager, each marked “(with no user details)”.

The Cowork article points reporting readers to the usage-report roles above. It does not set separate role requirements for the Value or Settings tabs. The two summary-only roles are listed “(with no user details)”, so verify their Cowork view in the tenant. Global Reader is not in the usage-report role list, so do not assume it grants access.

Other roles that Microsoft names: Global administrator and Billing administrator for billing methods; AI administrator for editing, but not creating, spending policies; a tenant administrator or the Copilot administrator role for Manage plugins for Cowork > Go to Tools (whether that is the AI Administrator role is not documented); and AI Admin, Security Admin, or Office Apps Admin for Frontier enrolment. License administrator permissions are unresolved: the Managing usage-based billing article lists that role both among those who “can edit spending policies” and among reader roles that “don't allow administrators to create or change spending policies”. Test it in the tenant before relying on either statement.

Viva Insights: Consumption Dashboard

The Cowork page follows the dashboard's roles:

RoleAccess and scope

  • Analysts in other partitions cannot run consumption queries, and “If you remove an analyst from the global partition, they lose access to all experiences in the global partition.”
  • Managers need Manager settings to allow it, a minimum team size of five or more, and Copilot insights access. The consumption article says “By default, consumption insights are enabled for all managers.” The Manager settings article says “Optionally, select Grant managers scoped access to Consumption insights.” Microsoft's articles differ, so check the setting in the tenant.
Delegation: Microsoft's articles disagree

Microsoft's articles disagree. How to use the Consumption Dashboard says access can't currently be delegated. Delegate access describes a Combined access delegate scope that includes the Consumption Dashboard. Test in the tenant before relying on either, and review existing delegates' scopes. The Delegate access article adds: “If you have both company-level and group access, any existing delegates previously set to "Your company" automatically have "Combined access" and might see the Consumption Dashboard.”

Named users and privacy

Copilot Analytics outputs are de-identified by default. Identification lets authorised users see named employees (“identified outputs”). Microsoft lists it for Consumption Dashboard insights and data export, and lists Copilot Dashboard and Agent Dashboard data exports as private preview. For the Agent Dashboard, Microsoft's articles disagree: Identification says private preview, while Export data from the Agent Dashboard says identifiable export “is for public preview customers only”. Validate availability in the tenant before relying on either. Access is governed by a dedicated Viva feature access management (VFAM) policy, which only a Microsoft 365 Global Administrator or an AI Administrator can create. When identifiable export is enabled for a user, their export includes identifiable fields. Otherwise, personal identifiers are replaced with anonymised IDs.

The admin center works differently. Its Cowork usage details table defines User ID as “The user's email address.”, but the usage reports overview states: “By default, all reports hide user information such as usernames, display names, groups, and sites to help companies support local privacy laws.” Check the tenant's Conceal user, group, and site names in all reports setting, and verify the Cowork table and export with the intended reporting role. Microsoft does not document the Viva Insights Identification policy as applying to this admin center report.

4. Operating the Cowork Dashboards

Complete Section 3 first. Tasks 1 to 3 use the admin center; task 4 uses Viva Insights.

Task 1 — Open the Cowork dashboard in the admin center

  1. Sign in to the Microsoft 365 admin center with a role from Section 2.
  2. In the left navigation, select Copilot.
  3. Under the Copilot section, select Cowork.
  4. Check the Last updated timestamp in the upper-right corner before you read any figure.

Verify: the dashboard opens and shows a Last updated timestamp. Microsoft does not document this dashboard's refresh latency, so rely on the timestamp.

Task 2 — Read the Overview and Usage tabs

  1. On Overview, read the headline cards, Active Cowork users and Total Cowork tasks. If a banner shows, read the Grace period card.
  2. Under Top actions for you, review Pending requests for Cowork.
  3. Select the Usage tab and set the Date range selector; the default is the past 28 days.
  4. Read the four cards and the Daily active users and Tasks by type charts.
  5. Review the Cowork usage details table, which lists individual users.

Verify: change the date range and confirm that the cards, charts, and table all change. Microsoft states: “All summary metrics, charts, and the usage details table update to reflect the selected time period.”

Microsoft defines a task as “a single conversation thread within Cowork, including both user-initiated conversations and scheduled task executions”. How “event-driven tasks that run when a matching email arrives or when a Teams message is posted, including when you're @mentioned” are counted is not documented.

Task 3 — Review the Value tab (Frontier preview)

Complete the Frontier check in Section 3 first, and read Section 5 before you quote any figure.

  1. Go to Copilot > Cowork, then select the Value tab.
  2. Choose the Date range: Last 28 days or Month to date.
  3. Read the Cowork assisted hours card and the Assisted hours by task category table.

Verify: you see the card and the table for the range you chose, with data “through the latest available data refresh”. If the tab is missing, check Frontier enrolment (Section 3); Microsoft does not document when the tab appears.

Task 4 — Read the Cowork page in the Consumption Dashboard

You need a role from Section 2 and usage-based billing set up. The release note says the dashboard “is enabled by default and requires usage-based billing setup via Cost Management in the Microsoft 365 admin center”.

  1. Open the Consumption Dashboard in Viva Insights.
  2. On the Microsoft 365 services tab, set Scope, Organization, and Job function (the Time period is month to date), then select Deep dive next to Cowork.
  3. Read the three cards: Cowork active users, Cowork Credit usage, and Average tasks per user.
  4. Use Cowork usage trends and Cowork usage breakdown by task, where Metric toggles total credits used or total task count.
  5. Review Usage intensity, which Microsoft describes as “similar to the insights shown on the previous page”.

Verify: the cards show month-to-date values and change when you change Scope, Organization, or Job function. Microsoft defines the metrics in the Copilot Cowork metrics section of the Advanced analysis metrics page, so this guide does not repeat them.

5. Reading Assisted Hours Safely

Cowork assisted hours appears on the admin center Value tab; the Consumption Dashboard Cowork page refers to “assisted value”. Microsoft's caveats are in the box at the top of this guide, and Microsoft adds: “Actual impact may vary based on the work performed and how Cowork is used.”

  • Method. “Each task is matched to a task type and assigned a typical time impact based on independent published research.” The Value tab links to the Cowork Time-Savings Methodology (PDF), which states “Each task category gets a minutes-saved range, traceable to a published study.”
  • Categories. The deck groups tasks into eight categories. The metrics page labels one “Document & comment task”, while the Value tab and the deck say document and content creation. The labels differ, and this guide does not resolve them.
  • Deck consistency. The deck's cover reads “COWORK TIME-SAVINGS METHODOLOGY v4” while its footers read “Cowork Effort-Band Methodology · v3 (additive)”, so this guide quotes none of its minute values. The aggregation formula and the handling of unclassified tasks are not documented.
  • Not the Copilot Dashboard metric. Copilot Dashboard Assisted Hours multiplies Copilot actions by an assistance factor, and Assisted Value applies an hourly rate (“By default, this hourly rate is set to $72”). No Cowork rate or currency is documented as of 2 October 2026. Do not add, compare, or trend the two metrics. The Dashboard Guide covers the Copilot Dashboard metrics.
  1. Quote it as a directional estimate of work supported, in Microsoft's wording, never as time saved, a productivity gain, or realised value.
  2. Read it by task category, next to Credits spent: “The number of Copilot credits used for tasks assigned to the category during the selected time period.”
  3. Record the surface, date range, Frontier status, and methodology link with every figure, and do not convert it to money.

6. Export and Reconciliation

Admin center export (usage details)

The usage details table lists users with activity “dating back to April 1, 2026”. Microsoft states: “Select Export above the usage details to download the full dataset as a CSV file. The exported file includes all users listed in the table.” The CSV headers, encoding, and row limits are not documented, and User ID is an email address, so treat the file as personal data.

Consumption Dashboard export (public preview)

  2. Keep both CSV files together and join them only on PeopleHistoricalId.

Where Microsoft's articles disagree

These disagreements are unresolved, and this guide does not call either article newer or more correct. Validate each one in the tenant, for example with a pilot manager for export, and compare your exported counts with both definitions. Delegation and the manager default are in Section 2.

TopicOne article saysAnother article says
Manager exportExport AI cost metrics: “Data export for Managers will be available by the end of July.”Configure manager settings: the checkbox allows “team-scoped data in the Consumption Dashboard and export data”.
Tasks and billed sessionsAdvanced analysis metrics: “A Cowork credit session is defined as a task or a conversation occurring within Copilot Cowork, which includes scheduled tasks.”How to use the Consumption Dashboard: “Multiple Cowork tasks, particularly scheduled tasks, can map to one billed session”.

Reconcile the figures

Tasks, credit sessions, and credits are different counts: “Copilot Cowork tasks and Cowork sessions measure different types of activity.” The two surfaces can also differ because of:

  • Scope. Viva Insights follows Scope, Organization, and Job function, while the admin center table “lists individual users”, subject to the report privacy setting in Section 2. Microsoft's minimum-group-size setting is documented for the Copilot Dashboard and Agent Dashboard, so verify any small-group suppression in the Consumption Dashboard in the tenant.
  • Active-user wording. The admin center counts users who “submitted at least one prompt in a Cowork task (conversational request), or had at least one scheduled task executed by Cowork on their behalf”. The Consumption Dashboard counts “unique users who took at least one action in Copilot Cowork or the Work IQ API”.
  • Time window. The Usage tab defaults to the past 28 days, and the Consumption Dashboard shows month to date.

For money, use the billing record: “In the Microsoft 365 admin center, you can use Billing > Bills & payments to view invoices and a high-level snapshot of charges associated with your billing account.”

  1. Record the surface, tab, date range, scope, and filters for each figure.
  2. Compare like with like: admin center tasks with admin center tasks, and Consumption Dashboard credits with Copilot > Cost management credits for the same policy and period, never task counts with session counts.
  3. Document any unexplained difference instead of forcing totals to match.

Verify: every difference is explained by a cause above or logged as unexplained.

7. Success Criteria

Before you rely on a recurring Cowork review, verify all of the following:

  • Each reviewer's role opens only the surfaces and scopes that Section 2 documents, and a manager cannot switch to Company scope.
  • The spending policies that select Cowork match the intended population of Cowork users.
  • The admin center tabs show a Last updated timestamp, and changing the date range changes every card, chart, and table.
  • The Value tab is either visible after the Frontier check or recorded as not available, and every assisted-hours figure carries its date range, surface, and caveat.
  • The Consumption Dashboard Cowork page responds to the Scope, Organization, and Job function filters, exports are stored under access controls that suit personal data, and money is reconciled in the billing record.
  • No availability promise has been made for GCC or any other national cloud.

8. Troubleshooting and Escalation

SymptomWhat Microsoft documentsAction
A user can use Cowork and you did not intend it“Access is decided per service by whether any applicable policy selects that service.” “A more restrictive policy doesn't override a more permissive one.”List the spending policies that select Cowork, then remove the user from their scope.
A low limit does not keep a user out, or a user continues after the limit“A policy with a limit of one credit still grants access.” “Credit limits are a spending safeguard, not a real-time access gate.”Control access through policy scope, not limits, and expect short overruns.
How do I disable Cowork for specific users?The FAQ: “Disable for specific users: Add users to a security group configured to exclude them from the Copilot experience.” The access article: “To keep a user out of Cowork, don't include them in any spending policy that selects Cowork.”The routes differ, and this guide does not choose between them. Test in a pilot group.
Users cannot find Cowork or see a request promptIf an admin makes Cowork discoverable without enabling usage-based billing, “end users can request to access Cowork directly in the app”.Review Pending requests for Cowork on the Overview tab.
The Consumption Dashboard is blank or zero“Consumption data is currently available only for Copilot Cowork and the Work IQ API.”Confirm usage-based billing set-up and month-to-date Cowork activity, and clear filters.

Escalation evidence

Before escalating, capture the tenant cloud environment, the viewer's role, the surface and tab, the date range, scope, and filters, the Last updated timestamp, the spending policies that select Cowork (with scope and limits), the exact error text, and any relevant Message Center or Service Health advisory. Route role and policy issues to the Microsoft 365 administrator who owns Copilot settings, access and Manager-settings issues to the Insights Administrator, billing differences to the billing administrator, and unresolved availability or data questions to Microsoft Support.
