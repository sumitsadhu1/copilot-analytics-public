1. Glossary of Key Terms

TermDefinition
AI Administrator Entra ID role that manages applicable AI and Copilot Dashboard settings, access assignment, exclusions, and feature controls. It does not grant automatic Copilot Dashboard viewing or Insights Analyst query rights.
Assisted Hours An estimate of the total time employees were assisted by using Copilot, computed from their actions in Copilot and multipliers derived from Microsoft research. It is a general estimate, not a measurement of time saved. Shown on the Dashboard Impact page for the past 28 days.
Assisted Value An estimate of the value of Copilot’s impact over the period, calculated as Assisted Hours × Loaded Labour Rate. Default rate is $72/hour (session-only, not persistent). Customers should adjust to their own rate.
Auto-enablement The process by which eligible users — senior leaders identified from Microsoft Entra manager-hierarchy data — are automatically enabled for access to the Copilot Dashboard and Agent Dashboard. It is controlled by the “Copilot Dashboard Auto Enablement” Viva Feature Access Management control (PowerShell feature ID AutoCxoIdentification), which is managed with PowerShell at tenant level only; Microsoft states that user- and group-level policies aren’t supported for this feature and won’t take effect. It does not assign Copilot licences.
Copilot Analytics Reports Ready-to-use and shared reports in the Viva Insights web app (Reports on the left), available to people who already have Copilot Dashboard access. Out-of-the-box reports include Copilot Studio agents and Copilot for Sales adoption; analysts can also share reports with leaders and managers. Unlike custom Power BI queries, these reports cannot be customized. The Copilot adoption and impact reports are Advanced Reporting Power BI templates for Insights Analysts.
Copilot Chat The current merged usage metric for the supported Copilot Chat experience. “Copilot Chat (legacy web)” is a legacy transition series that is expected to trend toward zero; do not interpret that legacy decline as an adoption decline by itself. Unlicensed Chat users have a dedicated Microsoft 365 admin center usage report.
Copilot Cowork A Microsoft Copilot experience that carries out tasks on a user’s behalf, such as sending emails, creating documents, scheduling meetings and searching across the organisation. A Cowork task is a single conversation thread (user-initiated or scheduled); an active Cowork user submitted at least one prompt in a task or had a scheduled task run for them. Usage is reported in the Microsoft 365 admin center (Copilot → Cowork) and the Consumption Dashboard; see Cowork Dashboard Operations.
Copilot Credits The common currency for eligible Microsoft services with usage-based billing. Usage-based experiences, such as Copilot Cowork, consume Copilot Credits and require a user subscription licence for access. Credit consumption is monitored in the Microsoft 365 admin center Cost management dashboard and the Insights Consumption Dashboard; both are operational views, not invoices. Use the monthly billing record in the applicable billing portal for reconciliation.
Consumption Dashboard One of Microsoft’s six Copilot Analytics areas. It shows how Copilot Credits and GitHub AI Credits are consumed across agents, services and users, on a Microsoft 365 services page (currently Copilot Cowork and the Work IQ API, with a Cowork deep-dive page; see Cowork Dashboard Operations) and a GitHub page (public preview). Identification can surface named employees where enabled. It is an operational analytics view for reference only, not the invoice or official billing ledger.
Cowork assisted hours A directional estimate of employee hours that benefited from Copilot Cowork in the selected period, calculated with a methodology optimised for Cowork. Microsoft states it is not a direct measurement of time saved, productivity gains, business outcomes or realised value. Shown on the Value tab of the Copilot Cowork usage dashboard (Frontier preview) and listed as a Cowork metric for the Consumption Dashboard in the Advanced analysis metrics reference. Not the same metric as Copilot assisted hours. See Cowork Dashboard Operations.
Delegated Access A mechanism where an eligible Dashboard user grants another user access to Copilot insights within the delegator’s permitted scope. A senior leader who has company-level access and is a manager chooses each delegate’s scope: Your group, Your company or Combined access. A group-scoped delegate sees the delegator’s group. A “Your company” delegate sees company-level data in the Copilot Dashboard, Agent Dashboard and Copilot Analytics reports, but not the Consumption Dashboard; Combined access includes the Consumption Dashboard, and a delegate with it sees exactly what the delegator sees. Agent Dashboard access needs “Your company” or “Combined access”. A delegate can’t delegate further; the maximum is 75 delegates. If the delegator has both company-level and group access, existing “Your company” delegates automatically become Combined access, so review delegate scopes. Microsoft’s articles disagree on Consumption Dashboard delegation: How to use the Consumption Dashboard says access can’t currently be delegated, while Delegate access describes a Combined access scope that includes it. Test in the tenant before relying on either. Delegation does not add an admin or analyst role.
Exclusion List A unified list of users hidden from aggregated insights in the Copilot Dashboard, Agent Dashboard, Consumption Dashboard and Viva Insights collaboration reports. Created by an AI Administrator through the Viva Feature Access Management unified exclusion list control (the VFAM table also lists a Viva Insights admin). Microsoft states: “After you remove users with an exclusion list, it will take up to three days for the changes to take effect.” Verify the resulting membership and report behaviour in the tenant after that window.
Grace period (Copilot Cowork) The number of days remaining in an organisation’s usage-based billing grace period before action is required to prevent loss of Cowork access. The Copilot Cowork usage dashboard in the Microsoft 365 admin center shows a banner and countdown, and a “Set up consumptive billing” action, while a grace period is active. See Cowork Dashboard Operations.
Identification (identified outputs) The set of capabilities that lets an organisation move from anonymized metrics to known users, surfacing named employees (“identified outputs”) when added precision is needed and permitted. It applies to Consumption Dashboard insights and exports and, in preview, to Copilot Dashboard and Agent Dashboard exports (Microsoft’s articles disagree on whether Agent Dashboard identifiable export is private or public preview). Access is governed by a dedicated Viva Feature Access Management policy that a Microsoft 365 Global Administrator or AI Administrator creates. Outputs are de-identified by default; when identifiable export is enabled for a user, their export includes identifiable fields. Treat identified outputs as a higher privacy classification than aggregated Dashboard metrics.
Insights Administrator Entra ID role responsible for configuring Viva Insights settings including privacy, partitions, organizational data, manager settings, and analyst assignments. Roles are independent and non-cumulative: Insights Administrator alone has no Insights Analyst query rights and no automatic Copilot Dashboard view.
Insights Analyst Entra ID role that can run person queries, access Power BI templates, and create custom reports within assigned partitions. Assignment to the Global partition also grants company-wide Copilot Dashboard access; assignment only to a non-Global partition does not.
Loaded Labour Rate The fully-burdened hourly cost of an employee, including salary, benefits, and overhead. Used to calculate Assisted Value. Default is $72/hour; organisations should substitute their own rate.
Minimum Group Size The smallest number of employees for which aggregated data is displayed on dashboards and in reports. Default is 10; lowest allowed is 5. Metrics are not shown for groups below this threshold.
Minimum Team Size The minimum size of a manager’s team — the manager plus all direct and indirect reports — for team-level insights to be available. The lowest allowed setting is 5. Configured separately from minimum group size.
Organizational Data Employee attribute data (department, location, job function, etc.) uploaded to Microsoft 365 to enable group filtering and segmentation on dashboards and in Power BI reports.
Partition An analyst workspace: it determines which employees (rows) and attributes (columns) an assigned Insights Analyst can query. Partitions scope analyst queries; they are not a tenant-wide security boundary (see Multi-Agency Reporting Pattern Decision).
Rolling Window The calculation period for a metric, not a universal retention limit. Many Dashboard measures use a 28-day rolling window with data latency; selected trendlines can span six months, the preview export provides six months weekly or 28 days daily, and Advanced Reporting retains up to 13 months of Copilot metric history.
Agent Dashboard (preview) A view of supported agent adoption and usage with two reporting views. The Copilot Agent Dashboard view is in public preview; Supported environments lists the Agent 365 Dashboard view as available (Yes) in Worldwide. Conservatively require 50 Microsoft Copilot licences plus agent activity because Microsoft sources conflict on the Viva-Insights-only route. Manager access is not settled by Microsoft’s sources: the Agent Dashboard article says enabled managers can see agent insights scoped to their teams, while the Roles in Viva Insights matrix lists no Manager access. Delegates need “Your company” or “Combined access”. Not available in GCC-M or GCC-H, or in other national or regional clouds.
Agent 365 Dashboard The second reporting view inside the Agent Dashboard, shown by selecting the All agents control at the top right; clearing that control returns the Copilot Agent Dashboard view. It covers all supported agents used across Microsoft 365 apps, reports sessions rather than agent responses, and does not show Copilot Credits. It requires Agent 365 licensing in addition to the base prerequisite — if the All agents control is absent, the tenant does not have it. Reporting history begins only from the date the organization accepted the Agent 365 terms of use, so it cannot be used for earlier baselines.
This guide’s implementation framework The guide’s optional five-stage rollout sequence. It is not a Microsoft product classification. Microsoft’s current official framing has six areas: admin center reports, Copilot Dashboard, Agent Dashboard, Consumption Dashboard, Copilot Analytics reports, and Advanced Reporting.
VFAM (Viva Feature Access Management) The admin control surface in the M365 Admin Center that enables or disables specific Viva features (e.g., Viva Insights web app, Agent Dashboard, Copilot metrics export) for the tenant or specific groups.

How to read the dates in this hub. A date shown next to a Microsoft Learn link — for example “(13 August 2026)” or “(Last updated 13 August 2026)” — is the “Last updated on” date Microsoft Learn displays on that page, not the date this hub checked it. A “Last validated” date is when this hub last re-verified its claims against those sources. See Change History for the current release and validation dates.
